# 📊 Prompt Canva – SuperCar

## Prompt principal (à coller dans Canva AI)

Crée une présentation de 10 slides pour un projet web scolaire "SuperCar" — site PHP/MySQL de vente de voitures d'occasion. Style moderne, palette orange #E67E22 / blanc / noir #1a1a1a, typographie Montserrat ou Poppins, fond alternant clair et sombre.

---

**Slide 1 – Titre**
SuperCar · Plateforme web de vente de véhicules d'occasion · Tagline : "Importation mondiale · Essai sur rendez-vous · Expérience premium" · Fond sombre avec voiture de sport, titre blanc, badge SC orange.

**Slide 2 – Présentation**
Qu'est-ce que SuperCar ? · Vente de voitures d'occasion haut de gamme · Importation depuis Japon, USA, Allemagne, France, Chine, Singapour, Afrique du Sud · 4 entrepôts · Showroom pour essais · Depuis 2009 · Fond clair avec icônes globe/voiture/entrepôt.

**Slide 3 – Stack technique**
Technologies : PHP (backend), MySQL (10 tables), Bootstrap 5 (responsive), JavaScript/AJAX (filtrage dynamique), CSS Animations, XAMPP · Grille 2×3 de cartes avec logo tech, fond sombre.

**Slide 4 – Base de données**
10 tables : marques, voiture, image, client, login, admin, service, demande_essai, message, contenu · Tableau épuré avec alternance orange/gris sur fond blanc.

**Slide 5 – Pages du site**
9 pages : Accueil, Catalogue, Détails véhicule, Demande d'essai, Services, Contact, Connexion, Inscription, Profil · Grille 3×3 avec icône + titre, fond gris clair.

**Slide 6 – Catalogue AJAX**
Fonctionnalité vedette : filtrage par marque sans rechargement (AJAX+PHP), autocomplétion, animation des cartes, hover orange · Mockup d'écran annoté, fond sombre.

**Slide 7 – Authentification**
Sécurité : table login séparée, mot de passe hashé (password_hash), rôles user/admin en session, pages protégées, CAPTCHA inscription, déconnexion sécurisée · Schéma de flux, icônes verrou/bouclier, fond sombre.

**Slide 8 – Administration**
Panneau admin complet : tableau de bord (stats voitures/essais/messages), l'admin gère tout le site · Exemple : page d'accueil — modification du Hero (titre, image), section À propos, section Processus, tout en base de données · Split sidebar sombre + aperçu page, accents orange.

**Slide 9 – UI/UX**
Design : animations CSS (fadeInUp, cascade de cartes), hover orange sur les cartes, notifications flottantes avec barre de progression, 100% responsive, palette cohérente, Bootstrap Icons · Moodboard palette + exemples, fond blanc.

**Slide 10 – Bilan**
Réalisations : site full-stack PHP+MySQL, 9 pages + espace admin, 10 tables, authentification avec rôles, UX animée · Compétences : PHP, SQL (JOIN/CRUD), AJAX, CSS avancé, architecture backend/frontend · 1ère année BTS/formation web · Fond sombre, accents orange.

---

## Instructions de style pour Canva
- Ratio 16:9
- Couleur principale : #E67E22 · Secondaire : #1a1a1a
- Police : Montserrat Bold (titres) · Inter (texte)
- Transitions douces (fade/slide)
- Alterner fond clair #f8f9fa et fond sombre #1a1a1a entre les slides
